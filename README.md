# Alchemy releases

Signed release builds of Alchemy for Android TV and Fire TV. There is no source code here:
this repository only holds the downloads, and the app checks it for updates.

## Installing

1. Open the [latest release](../../releases/latest) and download the `.apk` file.
2. Install it on the device: with `adb install`, or on the device itself with an app such as
   Downloader, after allowing installs from unknown sources.

A newer release installs over an older one and keeps what's saved on the device.
